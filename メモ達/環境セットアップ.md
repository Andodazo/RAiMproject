**所要時間**: ゼロから始めて約 5〜10 時間(各種 DL 時間 + 初回ビルド時間含む)

**このドキュメントの特徴**: 2026/05/20 の Android 実機ビルド成功までの実体験ベース。Unity 6 + URP 移行を見越した構成。詰まったポイント全部記録済み。

## 🚨 最重要: 落とし穴TOP3(これ知らないと半日溶ける)

### 1. 日本語パス禁止

**Android Tools (Java/Gradle) は日本語パスを含むディレクトリで動作しない。**

```
❌ NG: H:\開発\RAiM_prot\...
✅ OK: C:\dev\RAiMproject\...
```

エラーメッセージ例:
> Project path contains non-ASCII characters at position 3, Android Tools don't work properly with non-ASCII paths.

確認すべきもの:
- プロジェクトフォルダのフルパス
- Windows ユーザー名(`C:\Users\<日本語名>\` ならアウト)
- Flutter SDK のインストールパス

### 2. NDK バージョンの整合性

Flutter プラグインと Unity の NDK 要求が違うとビルド失敗。

実エラー:
```
audioplayers_android requires Android NDK 27.0.12077973
flutter_embed_unity_2022_3_android requires Android NDK 27.0.12077973
```

**解決**: `android/app/build.gradle.kts` で `ndkVersion = "27.0.12077973"` を明示。

### 3. unityLibrary を Git にコミットしない

`android/unityLibrary/` は Unity Export で生成される数千ファイル・数GB。

```gitignore
android/unityLibrary/
android/.gradle/
ios/UnityFramework/
ios/UnityLibrary/
```

詳細は `Git運用ルール.md` 参照。

## Phase 1: Windows 基礎セットアップ

### 1.1 Git

1. https://git-scm.com/download/win から DL してインストール
2. 設定:
   ```powershell
   git config --global user.name "Your Name"
   git config --global user.email "your@email.com"
   git config --global core.autocrlf input
   ```

### 1.2 Visual Studio Code

1. https://code.visualstudio.com/ から DL
2. 推奨拡張機能:
   - **Flutter** (Dart-Code.flutter)
   - **Dart** (Dart-Code.dart-code)
   - **GitLens** (eamodio.gitlens)
   - **Material Icon Theme** (PKief.material-icon-theme)

### 1.3 Visual Studio Community 2022

Flutter Windows ビルドに必須。

1. https://visualstudio.microsoft.com/ja/downloads/ から DL
2. **「C++ によるデスクトップ開発」** ワークロードを選択

### 1.4 Android Studio + SDK

1. https://developer.android.com/studio から DL してインストール
2. 初回起動時に「Standard」セットアップ
3. `File > Settings > Languages & Frameworks > Android SDK`:
   - `SDK Platforms`: **Android 14 (API 34)** または **Android 15 (API 35)**
   - `SDK Tools` タブで「Show Package Details」チェック後、以下にチェック:
     - ☑ **Android SDK Command-line Tools (latest)**
     - ☑ **Android SDK Build-Tools 34.0.0 以降**
     - ☑ **Android SDK Platform-Tools(最新)**
     - ☑ **NDK (Side by side) 27.0.12077973**
4. Apply → ダウンロード(10〜30 分)

### 1.5 Flutter SDK

1. https://flutter.dev/docs/get-started/install/windows から DL
2. **`C:\flutter\` のような ASCII パスに展開**
3. 環境変数 `Path` に `C:\flutter\bin` を追加
4. PowerShell を再起動して確認:
   ```powershell
   flutter --version
   ```

### 1.6 Android ライセンス + Doctor

```powershell
flutter doctor --android-licenses
```

`y` を 10 回連打。

```powershell
flutter doctor
```

全て `✓` になれば OK。

## Phase 2: Unity 6 環境セットアップ(主流)

> **方針**: RAiM プロジェクトは Unity 6000.0 LTS を主流とする。uPiper(TTS)等の最新パッケージが Unity 6 必須のため。

### 2.1 Unity Hub

1. https://unity.com/download から Unity Hub DL
2. インストール、Unity ID でログイン(Personal ライセンスで OK)

### 2.2 Unity 6000.0 LTS インストール

1. Unity Hub → Installs → Install Editor
2. **Long Term Support** タブから **6000.0 LTS** を選択
   - 最新の **6000.0.58f2 以降**を選ぶこと(`flutter_embed_unity` のセキュリティ要件)
3. インストール時のモジュール:
   - ☑ **Android Build Support**(IL2CPP, NDK, SDK 含む)
   - ☑ **iOS Build Support**
   - ☑ **Windows Build Support (IL2CPP)**
   - 日本語パックは任意

ダウンロード約 4〜6GB、10〜30 分。

### 2.3 Unity プロジェクトの開き方

#### 既存プロジェクトを開く場合(RAiM 既存)

1. Unity Hub → Projects → 「Add」ボタン
2. `C:\dev\RAiMproject\unity\raim_unity\` を選択
3. Editor バージョンに **6000.0 LTS** を指定
4. 「Open」
5. Unity 2022.3 から 6 へのアップグレードダイアログが出る → **Upgrade**
6. 初回起動は時間がかかる(`Library/` 再生成、5〜10 分)

⚠️ アップグレード後にエラーが大量に出る場合は、Phase 9「Unity 6 アップグレード詳細」を参照。

#### 新規プロジェクトを作成する場合

URP テンプレートを使う:
1. Unity Hub → Projects → 「New project」
2. **Universal 3D** テンプレートを選択
3. Editor バージョン: 6000.0 LTS

### 2.4 必須パッケージのインストール

Unity Editor で `Window > Package Manager` を開いて確認・追加する。

#### 必須パッケージ一覧

| パッケージ | 役割 | バージョン |
|---|---|---|
| **Universal RP**(URP) | Render Pipeline、flutter_embed_unity 必須 | Unity 6 同梱 |
| **flutter_embed_unity_6000_0** | Flutter ↔ Unity 連携 | git URL |
| **NativeWebSocket** | Windows 開発時の WebSocket 通信 | git URL |
| **2D Sprite**(任意) | スプライト描画 | Unity 6 同梱 |
| **TextMeshPro** | UI テキスト | Unity 6 同梱 |

#### 2.4.1 flutter_embed_unity の導入(Unity 6 用)

Package Manager で:
1. 左上の `+` → **Add package from git URL**
2. 以下を貼り付けて Enter:

```
https://github.com/learntoflutter/flutter_embed_unity.git?path=example_unity_6000_0_project/Assets/FlutterEmbed
```

これが Unity 6 用の参照。

⚠️ 公式 README では「.unitypackage を DL してインポート」を推奨しているが、現状の RAiM プロジェクトは **git URL 参照方式**を採用している。バージョン管理がしやすい。

代替手段(`.unitypackage` ファイル):
- https://github.com/learntoflutter/flutter_embed_unity/releases
- Unity 6 用: `flutter_embed_unity_6000_0.unitypackage` をダウンロード
- `Assets > Import package > Custom package` でインポート

#### 2.4.2 NativeWebSocket の導入

Package Manager で:
1. `+` → **Add package from git URL**
2. 以下を貼り付け:

```
https://github.com/endel/NativeWebSocket.git#upm
```

Windows 版で Flutter ↔ Unity の WebSocket 通信に必須。

#### 2.4.3 Universal RP の確認

Unity 6 では URP が標準だが、念のため Package Manager で「Universal RP」が入っていることを確認。

入っていなければ:
1. Package Manager → Unity Registry
2. `Universal RP` を検索
3. Install

### 2.5 Player Settings 必須項目

`Edit > Project Settings > Player > Other Settings` で以下を設定:

#### 共通設定

- **Scripting Backend**: `IL2CPP`(必須)
- **API Compatibility Level**: `.NET Standard 2.1`
- **Bundle Identifier**: `com.<自分の組織>.raim`(他人と衝突しないように)

#### Android 専用

- **Target API Level**: Flutter プロジェクトと合わせる(API 34 推奨)
- **Minimum API Level**: 23 以上(Unity 6 要件)
- **Target Architectures**:
  - ☑ ARMv7
  - ☑ ARM64

#### iOS 専用

- **Target minimum iOS Version**: 13.0 以上(Unity 6 要件)
- **Architecture**: ARM64(iOS は ARM64 のみ)

### 2.6 Build Settings 確認

`File > Build Profiles`(Unity 6 のメニュー、2022.3 では `Build Settings`):

- プラットフォーム: Android(または iOS)
- **Export Project**: ☑ ON(必須)

### 2.7 Camera 設定(透過、重要)

Unity 領域を Flutter UI に重ねる時、Unity の背景が黒くなる事故が頻発する。Main Camera の設定で予防:

1. SampleScene を開く
2. Hierarchy で Main Camera 選択
3. Inspector → Camera コンポーネント
4. **Clear Flags**: `Solid Color`
5. **Background** カラー: アルファ値を **0**(完全透過)
6. シーン保存

⚠️ これを忘れると Phase 5 のビルド後に**立ち絵の背景が黒い**問題が発生(2026/05/20 の実体験)。

### 2.8 Android SDK パス統一

Unity と Android Studio で別々の Android SDK 使うと事故る。

Unity Editor で:
- `Edit > Preferences > External Tools`
- Android SDK Tools: Android Studio が使ってる SDK パスに合わせる
  - 通常: `C:\Users\<ユーザー名>\AppData\Local\Android\Sdk`
- JDK: Unity 内蔵 JDK で OK
- Android NDK: Unity 内蔵 NDK で OK(Flutter 側で上書き)

## Phase 5: Android 実機ビルド(2026/05/20 成功実績)

### 5.1 Unity Export(Android)

Unity Editor で:

```
Window > Flutter Embed Unity > Export Android
```

通常の Build Settings → Build じゃなく、このメニューを使う。

完了後、`android/unityLibrary/` が生成される。

### 5.2 ⚠️ Unity Export 後の Git 操作

VS Code で**大量の変更(数千ファイル)**が表示されるが、**絶対にコミットしない**。

`.gitignore` 確認:
```gitignore
android/unityLibrary/
android/.gradle/
ios/UnityFramework/
ios/UnityLibrary/
```

詳細は `Git運用ルール.md` 参照。

### 5.3 ⚠️ Gradle 設定 4 ファイル修正(最重要)

これが今夜一番ハマったポイント。**必ず 4 ファイル全部修正**。

#### ファイル1: `android/settings.gradle.kts`

末尾に追加:

```kotlin
include(":app")

// === flutter_embed_unity 追加 ===
include(":unityLibrary")
project(":unityLibrary").projectDir = file("./unityLibrary")
```

#### ファイル2: `android/build.gradle.kts`(プロジェクトルートの方)

`allprojects { repositories { ... } }` 内に flatDir 追加:

```kotlin
allprojects {
    repositories {
        google()
        mavenCentral()
        // === flutter_embed_unity 追加 ===
        flatDir {
            dirs(file("${project(":unityLibrary").projectDir}/libs"))
        }
    }
}
```

#### ファイル3: `android/app/build.gradle.kts`

```kotlin
android {
    namespace = "com.example.raim_prototype"
    compileSdk = flutter.compileSdkVersion
    
    // === 重要: NDK 27(プラグイン要求と整合) ===
    ndkVersion = "27.0.12077973"
    
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_17
        targetCompatibility = JavaVersion.VERSION_17
    }
    
    kotlinOptions {
        jvmTarget = JavaVersion.VERSION_17.toString()
    }
    
    defaultConfig {
        applicationId = "com.example.raim_prototype"
        // === 重要: minSdk 23 以上(Unity 6 要件) ===
        minSdk = 23
        targetSdk = flutter.targetSdkVersion
        versionCode = flutter.versionCode
        versionName = flutter.versionName
        
        // ⚠️ ABI 制限は入れないこと(両 ABI 含む)
        // ndk { abiFilters += listOf("arm64-v8a") }
    }
    
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("debug")
        }
    }
}

// === flutter_embed_unity 追加 ===
dependencies {
    implementation(project(":unityLibrary"))
}

flutter {
    source = "../.."
}
```

#### ファイル4: `android/gradle.properties`

末尾に追加:

```properties
# === flutter_embed_unity 追加 ===
unityStreamingAssets=
```


## Phase 10: uPiper 統合(オプション、TTS のモバイルオフライン化)

uPiper は Unity 内蔵 TTS パッケージ。Unity 6 必須。

**目的**: モバイル(iOS/Android)で**オフライン**で音声合成する選択肢を持つこと。本番採用は VOICEVOX(クラウド)だが、uPiper は比較検証用。

**詳細**: `TTS比較.md` 参照

### 10.1 前提

- ✅ Unity 6000.0.58f2 以降がインストール済み
- ✅ Phase 9 の Unity 6 アップグレード完了
- ✅ Unity AI Inference Engine 2.2.2 が利用可能(Unity 6 標準)

### 10.2 uPiper のインストール

Package Manager で:

1. `+` → **Add package from git URL**
2. 以下を貼り付け(バージョン v1.2.0 推奨):

```
https://github.com/ayutaz/uPiper.git?path=Assets/uPiper#v1.2.0
```

⚠️ v1.2.0 を選ぶ理由:
- 純 C# G2P 実装(ネイティブライブラリ不要)
- iOS/Android ビルドがシンプル
- それ以前のバージョンは C++ ネイティブライブラリ必要でビルド複雑

### 10.3 サンプル + 必須リソースのインポート

uPiper はモデルファイル等のサンプルを別途インポートする必要がある:

1. Package Manager で uPiper 選択
2. 右側パネルの **Samples** タブ
3. 以下をインポート:
   - ☑ **MeCab Dictionary Data**(日本語形態素解析必須)
   - ☑ **Voice Models**(音声モデル)
   - ☑ **Basic TTS Demo**(動作確認用)

### 10.4 セットアップ

メニュー: `uPiper > Setup > Install from Samples`

自動で必要なファイルが配置される。完了後:

`uPiper > Setup > Check Setup Status`

全項目が ✓ になっていれば成功。

### 10.5 RAiM への統合(将来の実装)

現状は uPiper の動作確認まで。RAiM プロジェクトへの統合は卒研後の発展課題。

統合イメージ(`RAiMCharacterController.cs` への追加):

```csharp
using uPiper;
using UnityEngine;

public class RAiMCharacterController : MonoBehaviour
{
    private PiperTTS piperTTS;
    private AudioSource audioSource;
    
    async void Start()
    {
        // ... 既存の初期化 ...
        
        // uPiper 初期化(モバイル時のみ)
#if UNITY_ANDROID || UNITY_IOS
        piperTTS = new PiperTTS();
        await piperTTS.InitializeAsync(modelPath);
        audioSource = gameObject.AddComponent<AudioSource>();
#endif
    }
    
    public async void ReceiveMessage(string json)
    {
        var data = JsonUtility.FromJson<EmotionMessage>(json);
        ChangeEmotion(data.emotion);
        
#if UNITY_ANDROID || UNITY_IOS
        // モバイルでは uPiper で発話
        var audioClip = await piperTTS.GenerateAudioAsync(data.text);
        audioSource.clip = audioClip;
        audioSource.Play();
#endif
        // Windows では Flutter 側の VOICEVOX で発話(変更なし)
    }
}
```

### 10.6 注意点

- **音質**: 公式作者も「精度向上中」と認めており、VOICEVOX に劣る
- **モデルサイズ**: 数十 MB、APK が肥大化する
- **動作確認**: 必ず実機で確認(エミュレータでは音声出ない)
