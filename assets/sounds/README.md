# assets/sounds

駅アラームでライムが知らせるときの声。VOICEVOX（春日部つむぎ）で作って置く。
ファイルが無くてもアプリは動く（通知の音とバイブだけで知らせる）。

| ファイル名 | 鳴らすとき | セリフの例 |
|---|---|---|
| `station_approaching.wav` | 隣の駅のアナウンスを聞いたとき | もうすぐ降りる駅だよ。準備しておいてね！ |
| `station_arriving.wav` | 降りる駅のアナウンスを聞いたとき | 着くよ！降りる準備して！起きて起きてー！ |
| `station_approaching_downer.wav` | 同上（ダウナー版） | もうすぐ降りる駅だよ。そろそろ準備しよ |
| `station_arriving_downer.wav` | 同上（ダウナー版） | ほら、着くよ。起きて。降りる準備して |

- ダウナー版はサーバーの人格が `downer` のときに鳴らす（サーバーが metadata / chat_end で知らせる）。
  ダウナー版のファイルが無ければ通常版を鳴らす。

- 形式は wav（VOICEVOX の書き出しのまま）でよい。
- 3〜4 秒以内に収める。鳴っている間は車内アナウンスを聞けないため
  （ライムの声に自分で反応しないよう、鳴らしている間は聞くのを止める）。
- 駅名は入れない（どの駅でも使えるように）。駅名は通知の文で出す。
