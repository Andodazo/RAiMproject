インストールのしかた

Android
  1. 「Android 版をダウンロード」を押して APK を保存します。
  2. ダウンロードした RAiM-android.apk を開きます。
  3. 「提供元不明のアプリ」の確認が出たら、ブラウザに許可を出してインストールします。
  4. 初回の起動時に、マイクと位置情報の許可を求められます。駅アラームを使うなら位置情報は「常に許可」にしてください。

開発中に PC から直接入れた版が残っていると、インストールに失敗することがあります。 その場合は古い RAiM を一度アンインストールしてから入れ直してください（最初の1回だけです）。

Windows
  1. 「Windows 版をダウンロード」を押して zip を保存します。
  2. zip を右クリック →「すべて展開」で好きな場所に展開します。
  3. 展開した RAiM フォルダの RAiM.exe を起動します。
  4. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。

unity フォルダの中身はライム本体です。RAiM.exe と同じ場所に置いたままにしてください。

新しい版が出たとき
  1. このページから同じようにダウンロードします。
  2. Android：そのままインストールすると上書きされます。ログイン状態や設定は残ります。
  3. Windows：RAiM を終了してから、古い RAiM フォルダを消して、新しい zip を展開します。ログイン状態や設定は残ります。
iPhone / iPad

iPhone 版はこのページからは配布していません。 App Store の外でアプリを配るには Apple の有料の開発者登録が必要なためです。 試したい場合は開発メンバーに声をかけてください。
