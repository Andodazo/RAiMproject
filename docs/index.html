入れ方

Android

  1. ダウンロードした RAiM-android.apk を開く
  2. 「提供元不明のアプリ」の確認が出たら、ブラウザに許可を出してインストール
  3. 初回起動でマイクと位置情報の許可を聞かれる。駅アラームを使うなら位置情報は「常に許可」

サイズが大きいので Wi-Fi のあるところで入れてください。
flutter run で入れた RAiM が残っているとインストールに失敗します。先にアンインストールしてください（最初の1回だけ）。

Windows

  1. zip を右クリック →「すべて展開」
  2. 展開した RAiM フォルダの RAiM.exe を起動
  3. 「Windows によって PC が保護されました」が出たら「詳細情報」→「実行」

unity フォルダはライム本体です。RAiM.exe と同じ場所に置いたままにしてください。

新しい版が出たら

Android

同じボタンからダウンロードして、そのままインストールすれば上書きされます。ログインと設定はそのまま残ります。

Windows

RAiM を終了して、古い RAiM フォルダを新しい zip の中身に入れ替えてください。ログインと設定はそのまま残ります。

iPhone で使いたいとき

このページからは入れられません（Apple の有料登録が無いため）。Mac から直接入れるので、安藤に声をかけてください。
